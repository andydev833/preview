# reform テンプレート（3パターン）

リフォーム会社向けの営業サンプルHPテンプレート。3種類の視覚言語違い。

| パターン | ディレクトリ | 参考デザイン |
| --- | --- | --- |
| A: 温かみ・イラスト系 | `pattern-a/` | 株式会社KEEPs「雨漏りの窓口キープス」(https://keeps.homes/) |
| B: エディトリアル・モノトーン系 | `pattern-b/` | tetopaint（外壁・屋根塗装専門店, https://tetopaint.jp/） |
| C: テクスチャ・クラフト系 | `pattern-c/` | 石井造園株式会社（https://www.ishii-zouen.co.jp/） |

各 `pattern-*/index.html` は `{{TOKEN}}` プレースホルダを含む雛形。会社ごとの実ファイルは
`../../reform/{slug}/{a,b,c}/index.html` に生成する（生成スクリプトは
`../../scripts/generate_reform_previews.py`）。

## トークン一覧

| トークン | 内容 | 出典・埋め方 |
| --- | --- | --- |
| `{{COMPANY_NAME}}` | 会社名・屋号 | 営業リスト（実データ） |
| `{{COMPANY_INITIAL}}` | バッジ用の1文字 | 会社名の先頭1文字 |
| `{{AREA}}` | 対応エリア（市区町村） | 営業リスト（実データ） |
| `{{PHONE_HREF}}` | 連絡先リンクのhref | 電話番号があれば `tel:...`、なければ Google Maps URL |
| `{{PHONE_LABEL}}` | 連絡先リンクの表示文字 | 電話番号があればハイフン区切り表示、なければ「Google Mapsで確認する」 |
| `{{RATING_DISPLAY}}` | Google評価の表示 | 営業リスト（実データ）。不明なら「-」 |
| `{{CATEGORY_LABEL}}` | 業種表示 | 営業リストの `rawIndustry`（実データ） |
| `{{HOURS_NOTE}}` | 受付時間欄の文言 | 実際の営業時間が不明なため、断定しない一般的な案内文を既定値にする |
| `{{TAGLINE_EN}}` | ロゴ下の英字タグライン（B/Cのみ） | 会社の実績を騙る文言にしない（創業年など事実断定は禁止） |

## 守るべきこと

- **この3ファイルは雛形（テンプレート）であり、単体では開けない。** 実際に確認するときは
  `reform/{slug}/{a,b,c}/index.html`（生成済みファイル）を開くこと。
- 会社ごとに生成する際、**実データがない項目は断定しない**（所在地の番地・建設業許可番号・
  創業年・具体的な施工実績数など、検証可能な事実を装う項目は雛形からすでに除去済み）。
- 工事事例・料金・工期は仮の掲載例で、会社固有の実績ではないことを各セクションに明示する。
  架空のお客様の声は掲載せず、未確認の自社施工・無料診断・保証条件も断定しない。
- 各ページ先頭の「こちらはご提案用のサンプルページです」バナーと `<meta name="robots"
  content="noindex, nofollow">` は削除しない。正式受注後、本番切り替え時にのみ外す。

## 連絡先・画像・検証

- 電話番号がない場合は、Google Mapsを「店舗情報・連絡先の確認」として表示する。
- 任意の `lineUrl`（HTTPS）を会社データに指定するとLINEリンクが有効になる。
  未設定時は「LINE準備中（サンプル）」と表示し、遷移しない。追従バーの補助リンクは工事掲載例へ移動する。
- `CONTACT_ICON`、`CONTACT_NOTE`、`CONTACT_FLOW`、`LINE_ATTRIBUTES`、`LINE_LABEL`、`IMAGE_SRC` は生成スクリプトで設定する。
- `assets/reform/interior-concept.webp` は組み込み画像生成ツールで作成した共通のイメージ画像。
  各表示箇所で「AI生成・実際の施工実績ではありません」と明記する。元の会社の現場写真ではない。
  生成プロンプトは「日本の住宅リフォームを想定した、オークの床・造作、白い塗り壁、セージ色のキッチン、庭からの自然光のある横長の建築写真風イメージ。人物・文字・ロゴなし」。
- 再生成: `python3 scripts/generate_reform_previews.py`
- 検証: `python3 scripts/validate_reform_previews.py`（96ページの文書設定・リンク・画像・電話分岐とLINE URL・文字エスケープ）
- 目視確認画像は `review/reform/` に保存。実機スマホではなくブラウザの390px幅で検証している。
